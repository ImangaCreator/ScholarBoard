# Scholarboard

Every scholarship you're applying to in one place. Group similar essay prompts, write one master essay per group, and tailor it for each scholarship.

## Stack

React, Vite, and Supabase (Supabase is wired in a later chunk).

## Run it

```bash
npm install
npm run dev
```

## Build order

1. Setup and Home page (this commit)
2. Scholarships database: table view, side panel
3. Board and calendar views
4. Essays page
5. Supabase: accounts and saved data
6. Find, Materials, Profile
